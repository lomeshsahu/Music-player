How to get & restrict a free API key
  1. Open the Google Cloud Console.
  2. Create a project and enable YouTube Data API v3.
  3. Under Credentials, create an API Key.
  4. Recommended Security Restrictions:
    • Set Application Restrictions to Websites and add your domain (e.g. https://yourusername.github.io/* or http://localhost:*).
    • Set API Restrictions to strictly allow only YouTube Data API v3.
